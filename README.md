# 🎌 Guide Animés pour Débutants

Bienvenue sur mon tout premier projet web. 

Ce site a pour objectif d'aider les personnes qui souhaitent découvrir l'univers des animés japonais mais qui ne savent pas par où commencer.

## 🎯 Objectifs du projet
* **Pour les visiteurs :** Présenter les différents genres (Shonen, Shojo, Seinen, Slice of Life) et recommander des œuvres incontournables selon leurs goûts.
* **Pour moi :** Apprendre et pratiquer les bases du développement web (**HTML** et **CSS**) de manière ludique.

## 🛠️ Technologies utilisées
* **HTML** : Structure de la page
* **CSS** : Mise en page (Flexbox/Grid), couleurs et animations au survol
